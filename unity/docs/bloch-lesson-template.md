# Bloch Lesson Record — Template

Copy this file for each lesson. The birth metadata comes first and
is filled in at creation, before the lesson body is written: a
record without `origin_lane`, `content_label`, and `evidence` does
not exist (see the Bloch lane law in `../SKILLS.md`).

```yaml
title: ""
# One short, searchable sentence naming the lesson.

date: ""
# ISO date the lesson was learned, e.g. 2026-11-09.

origin_lane: ""
# Where the lesson was earned: the repo, template, or surface it
# came from (for this template: unity-game-shell, or the adopting
# project's name).

content_label: ""
# sfw or nsfw — the content classification that governs where this
# lesson may flow. When unsure, write nsfw: unclassified lessons
# are treated as nsfw, fail-closed. Changing nsfw to sfw later is a
# gated Owner/Pax act.

evidence: ""
# The artifact the lesson rests on: a gate log, a drill result, a
# file and line, a measured value. A claim with no citable artifact
# is not yet a lesson.
```
